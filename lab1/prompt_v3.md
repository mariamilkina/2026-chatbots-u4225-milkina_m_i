# Итерация 3 — персональные уроки EnglishMate

Расширь существующего Telegram-бота EnglishMate.

Сейчас бот умеет:
- проводить placement test;
- определять ориентировочный уровень A1–B2;
- выбирать цель обучения;
- сохранять данные пользователя в SQLite;
- показывать /progress;
- показывать /help;
- стабильно обрабатывать inline-кнопки.

Необходимо добавить полноценный учебный функционал.

## 1. Команда /lesson

Добавить команду /lesson.

При запуске урока бот должен получить из SQLite:
- текущий уровень пользователя;
- выбранную цель обучения.

На основе этих данных подобрать подходящий урок.

Примеры:
- A2 + Travel → английский для путешествий уровня A2;
- B1 + Speaking → разговорные задания уровня B1;
- B2 + Work → деловая лексика и грамматика уровня B2;
- B1 + General English → общий английский уровня B1.

Если пользователь ещё не прошёл placement test, бот должен предложить сначала пройти его через /start.

## 2. Структура урока

Один урок состоит из 5 заданий.

Использовать разные форматы.

### Multiple choice
- вопрос;
- 4 варианта ответа через inline-кнопки;
- один правильный ответ.

После ответа:
- сообщить, правильно или нет;
- показать правильный вариант;
- дать короткое объяснение.

### Свободный ответ
Пользователь пишет ответ текстом.

Например:
- перевод предложения;
- вставить слово;
- написать короткую фразу.

Бот должен проверить ответ и дать обратную связь.

## 3. Персонализация

Сложность задания должна соответствовать уровню пользователя.

Тематика должна учитывать цель:
- General English;
- Speaking;
- Travel;
- Work.

## 4. Результат урока

После 5 заданий показать:

- результат X/5;
- процент правильных ответов;
- краткий комментарий;
- рекомендацию, чему уделить внимание.

Сохранять результат урока в SQLite.

## 5. Прогресс

Расширить команду /progress.

Она должна показывать:

- уровень;
- цель;
- результат placement test;
- количество завершённых уроков;
- средний процент выполнения уроков.

## 6. Защита состояния

Если пользователь находится внутри урока:
- бот должен понимать, какое задание сейчас выполняется;
- ответы из старых вопросов не должны засчитываться;
- двойное нажатие кнопки не должно менять результат.

## 7. Команда /help

Показывать:

/start — пройти или повторить placement test
/lesson — начать персональный урок
/progress — посмотреть прогресс
/help — помощь

## Требования

- Python 3.9
- python-telegram-bot 22.5
- SQLite
- python-dotenv
- сохранить улучшения стабильности из v2
- не ломать placement test
- не хранить Telegram token в коде
