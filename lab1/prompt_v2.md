# Итерация 2 — оптимизация работы EnglishMate

Улучши существующего Telegram-бота EnglishMate.

Текущая версия уже умеет:
- проводить placement test из 12 вопросов;
- показывать 4 варианта ответа через inline-кнопки;
- определять ориентировочный уровень A1–B2;
- сохранять уровень, результат теста и цель пользователя в SQLite;
- показывать данные через /progress;
- выводить /help.

При тестировании обнаружены проблемы:
- после нажатия inline-кнопки бот иногда отвечает слишком долго;
- иногда пользователю приходится нажимать вариант ответа несколько раз;
- в логах периодически появляется telegram.error.TimedOut;
- одно нажатие вызывает несколько последовательных запросов к Telegram API.

Необходимо исправить эти проблемы, не ломая существующий функционал.

## Требования

1. После нажатия inline-кнопки сразу подтверждать callback query.

2. После выбора ответа убрать старые кнопки или сделать так, чтобы повторное нажатие не могло повторно засчитать ответ.

3. Защитить бота от двойной обработки одного ответа.

4. Оптимизировать отправку сообщений:
- по возможности не выполнять лишние запросы к Telegram API;
- пользователь должен быстро получать следующий вопрос.

5. Настроить увеличенные:
- connect timeout;
- read timeout;
- write timeout;
- pool timeout.

6. Добавить обработку:
- telegram.error.TimedOut;
- TelegramError;
- временных сетевых ошибок.

7. Единичный сетевой timeout не должен останавливать бота.

8. Добавить понятное логирование ошибок.

9. Сохранить весь существующий функционал:
- /start;
- placement test;
- inline-кнопки;
- определение уровня;
- выбор цели;
- SQLite;
- /progress;
- /help.

10. Совместимость:
- Python 3.9;
- python-telegram-bot 22.5;
- python-dotenv.

Не менять формат хранения TELEGRAM_BOT_TOKEN через .env.
