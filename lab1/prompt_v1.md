# Исходный промпт для LLM

Создай Telegram-бота на Python с использованием библиотеки python-telegram-bot.

Название бота: EnglishMate.

EnglishMate — персональный помощник для изучения английского языка.

Функционал первой версии:

1. Команда /start:
- приветствует пользователя;
- объясняет возможности бота;
- предлагает пройти тест для определения примерного уровня английского.

2. Placement test:
- 12 вопросов;
- каждый вопрос имеет 4 варианта ответа;
- варианты отображаются с помощью inline-кнопок Telegram;
- после выбора бот сохраняет ответ и показывает следующий вопрос;
- в конце подсчитывает результат.

3. По результатам теста определить ориентировочный уровень:
- A1
- A2
- B1
- B2

Это должна быть первичная оценка уровня, а не полноценная CEFR-сертификация.

4. После теста предложить выбрать цель обучения с помощью кнопок:
- General English
- Speaking
- Travel
- Work

5. Сохранять:
- Telegram ID пользователя;
- уровень;
- выбранную цель;
- результат теста.

Для хранения использовать SQLite.

6. Команда /progress показывает:
- уровень;
- цель;
- результат placement test.

7. Команда /help показывает доступные функции.

Требования:
- Python;
- python-telegram-bot;
- SQLite;
- понятный и прокомментированный код;
- обработка ошибок;
- токен Telegram получать из переменной окружения TELEGRAM_BOT_TOKEN;
- использовать .env;
- .env не должен попадать в Git;
- создать .env.example без реального токена.

Создай файлы:
- bot.py
- database.py
- requirements.txt
- .env.example
- README.md

Проект должен запускаться локально командой:

python bot.py
