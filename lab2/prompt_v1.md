### Исходный промпт для Lab 2

Улучши существующего Telegram-бота EnglishMate, добавив интеграцию с внешним источником данных.

Существующий бот уже умеет:

- проводить placement test;
- определять ориентировочный уровень английского A1–B2;
- сохранять цель обучения;
- проводить персональные уроки;
- проверять ответы;
- сохранять прогресс пользователя в SQLite;
- поддерживает команды /start, /lesson, /progress и /help.

Нужно сохранить весь существующий функционал и добавить работу с английским словарём через публичный Dictionary API.

### Новый функционал

Добавить команду:

/word <слово>

Пример:

/word opportunity

После команды бот должен обратиться к Dictionary API и получить данные о слове.

Показывать пользователю:

- слово;
- транскрипцию, если она доступна;
- часть речи;
- определение;
- пример использования, если он есть;
- до 3 синонимов, если они доступны.

Не выводить весь ответ API. Информация должна быть отформатирована коротко и понятно для изучающего английский.

### Сохранение слов

Под результатом поиска добавить inline-кнопку:

"Сохранить слово"

После нажатия слово должно сохраняться в SQLite для конкретного Telegram-пользователя.

Для сохранённого слова хранить:

- Telegram ID;
- слово;
- транскрипцию;
- часть речи;
- определение;
- пример;
- дату добавления.

Не сохранять одно и то же слово одному пользователю повторно.

### Команда /mywords

Добавить команду:

/mywords

Она должна показывать сохранённые пользователем слова.

Если слов пока нет, вывести понятное сообщение.

Если слов много, не отправлять слишком длинное сообщение: вывести последние 10 сохранённых слов.

### Обработка ошибок

Нужно корректно обрабатывать ситуации:

- пользователь написал /word без слова;
- слово не найдено;
- API временно недоступен;
- API вернул некорректный ответ;
- отсутствует часть необязательных данных, например транскрипция или пример;
- повторное сохранение слова.

Бот не должен завершать работу из-за ошибки внешнего API.

### API

Использовать публичный Dictionary API:

https://api.dictionaryapi.dev/api/v2/entries/en/<word>

API-ключ не требуется.

### Требования

- Python 3.9;
- python-telegram-bot 22.5;
- SQLite;
- python-dotenv;
- requests или httpx для работы с API;
- сохранить существующую обработку Telegram timeout;
- не хранить Telegram Bot Token в коде;
- существующий функционал EnglishMate не должен перестать работать.

Обнови:

1. bot.py
2. database.py
3. requirements.txt
4. README.md

Код должен быть понятным и содержать обработку ошибок.
