# Prompt v4

Доработай существующий Telegram-бот EnglishMate.

Сохрани весь уже работающий функционал из предыдущих версий:
- /start
- placement test
- выбор цели обучения
- /lesson
- /progress
- /help
- /word
- /mywords
- SQLite
- сохранение слов
- защита от дублей

Нужно улучшить словарь, потому что текущие Datamuse API и MyMemory дают не всегда корректные переводы и слишком слабые словарные данные.

Используй:

1. Merriam-Webster Learner's Dictionary API как основной источник английской словарной информации.
API key брать только из .env:
MERRIAM_WEBSTER_API_KEY

Не хранить API key прямо в коде.

2. Wiktionary использовать для получения нескольких русских переводов английского слова.
Для Wiktionary отдельный API key не нужен.

Команда:

/word <english_word>

Карточка должна быть компактной и понятной для человека, изучающего английский.

Пример:

Слово: arm
Часть речи: noun

Переводы:
• рука
• ручка
• рукав

Значение:
The part of the body from the shoulder to the hand.

Пример:
She held the baby in her arms.

Синонимы:
• limb
• branch

Требования:

- показывать часть речи;
- показывать до 3 наиболее понятных русских переводов;
- не показывать редкие, технические и странные переводы первыми;
- показывать одно основное английское определение;
- если Merriam-Webster возвращает пример использования, показывать один пример;
- показывать до 3 синонимов;
- не показывать IPA и лишние технические данные;
- не выводить десятки значений.

Если у слова есть несколько распространённых частей речи, например noun и verb, можно показать максимум 2 основных блока.

Например:

Слово: arm

1. noun
Переводы: рука, ручка, рукав
Значение: ...
Пример: ...
Синонимы: ...

2. verb
Переводы: вооружать, снабжать оружием
Значение: ...
Пример: ...

Кнопка «Сохранить слово» должна остаться.

При сохранении в SQLite сохранять:
- word
- translation
- part_of_speech
- definition
- example
- date

/mywords должен показывать сохранённые слова с переводом, например:

1. arm — рука, ручка, рукав
noun: The part of the body from the shoulder to the hand.

Обязательно сохранить обработку ошибок:

- /word без слова;
- слово не найдено;
- Merriam-Webster API временно недоступен;
- Wiktionary временно недоступен;
- отсутствует пример;
- отсутствуют синонимы;
- отсутствует русский перевод;
- повторное сохранение слова.

Если Wiktionary не отвечает, бот всё равно должен показать данные Merriam-Webster без русского перевода.

Если пример или синонимы отсутствуют, просто не показывать соответствующий блок.

Проект должен оставаться совместимым с:
- Python 3.9
- python-telegram-bot 22.5
- SQLite
- python-dotenv
- httpx

Обнови bot.py, database.py при необходимости, .env.example и README.md.

Не ломай существующие функции EnglishMate.
