# EnglishMate — Lab 2

EnglishMate — Telegram-бот для изучения английского языка.

Во второй лабораторной работе бот был дополнен работой с внешними данными:
- Merriam-Webster Learner's Dictionary API — часть речи, определения и примеры;
- Wiktionary — русские переводы;
- SQLite — сохранение слов пользователя.

## Возможности

Основные команды:

- `/start` — запуск бота;
- `/lesson` — персональный урок;
- `/progress` — прогресс пользователя;
- `/word <слово>` — поиск английского слова;
- `/mywords` — сохранённые слова;
- `/help` — помощь.

Пример:

```text
/word arm
```

Бот показывает до двух основных частей речи. Для каждой части речи могут отображаться:
- до 3 русских переводов;
- одно основное английское определение;
- пример использования.

Слово можно сохранить кнопкой **«Сохранить слово»**. Повторные записи не создаются.

## Технологии

- Python 3.9
- python-telegram-bot 22.5
- SQLite
- httpx
- python-dotenv
- Merriam-Webster Learner's Dictionary API
- Wiktionary

## Запуск

1. Создать виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

2. Установить зависимости:

```bash
python3 -m pip install -r requirements.txt
```

3. Создать `.env` на основе `.env.example`:

```text
TELEGRAM_BOT_TOKEN=your_bot_token
MERRIAM_WEBSTER_API_KEY=your_merriam_webster_api_key
```

Настоящие ключи не должны загружаться в GitHub.

4. Запустить бота:

```bash
python3 bot.py
```

## Обработка ошибок

Бот обрабатывает:
- `/word` без аргумента;
- неизвестное слово;
- временную недоступность внешнего API;
- отсутствие перевода или примера;
- повторное сохранение слова.

Если дополнительный источник перевода недоступен, бот старается показать доступные данные Merriam-Webster.
