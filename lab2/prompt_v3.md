### Итерация 3 — улучшение карточки слова

Текущая версия EnglishMate получает данные о слове через Datamuse API.

Во время тестирования выяснилось, что текущая выдача неудобна для пользователя:
- IPA и техническая транскрипция не нужны;
- дополнительные определения иногда слишком редкие или странные;
- карточка перегружена информацией;
- пользователю нужен русский перевод слова.

Необходимо улучшить команду /word.

### Новый формат ответа

Карточка должна выглядеть примерно так:

Слово: opportunity
Перевод: возможность, шанс
Часть речи: noun

Значение:
A chance for advancement, progress or profit.

Синонимы: chance, possibility

[Сохранить слово]

### Требования

1. Полностью убрать IPA и произношение из ответа.

2. Из Datamuse использовать:
- слово;
- часть речи;
- одно основное определение;
- до 3 подходящих синонимов.

3. Не показывать пользователю все определения из API.

4. Не выводить редкие, устаревшие или технические варианты, если есть нормальное основное определение.

5. Добавить перевод английского слова на русский.

Для перевода можно использовать отдельный публичный API.

Перевод является дополнительным источником данных:
- если перевод успешно получен — показать его;
- если сервис перевода временно недоступен — не ломать команду /word;
- в таком случае просто показать карточку без строки "Перевод".

6. Перевод должен быть коротким.
Для одного английского слова достаточно 1–2 русских вариантов.

7. Сохранить кнопку:

"Сохранить слово"

8. При сохранении слова в SQLite хранить также русский перевод, если он был получен.

9. Обновить /mywords.

Формат сохранённого слова:

opportunity — возможность, шанс
noun: A chance for advancement, progress or profit.

10. Не ломать существующий функционал:

- /start
- /lesson
- /progress
- /help
- /word
- /mywords
- placement test
- персональные уроки

11. Сохранить обработку ошибок внешних API.

Если один из дополнительных API недоступен, бот не должен завершать работу.

### Технические требования

- Python 3.9
- python-telegram-bot 22.5
- SQLite
- python-dotenv
- httpx
- Telegram Bot Token хранить только в .env
