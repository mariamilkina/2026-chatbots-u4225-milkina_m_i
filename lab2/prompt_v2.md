### Итерация 2 — замена нестабильного Dictionary API

При тестировании команды /word выяснилось, что первоначально выбранный Dictionary API периодически не отвечает и вызывает timeout.

Необходимо сохранить существующий функционал EnglishMate, но заменить внешний источник словарных данных на Datamuse API.

Использовать:

https://api.datamuse.com/words

Для поиска конкретного слова использовать параметры:

- sp=<word>
- md=dpr
- ipa=1
- max=1

Новый функционал /word должен показывать:

- слово;
- IPA-произношение, если доступно;
- часть речи;
- определение;
- при наличии несколько дополнительных определений.

Дополнительно можно получить до 3 синонимов отдельным запросом через relation rel_syn.

Сохранить существующую кнопку:

"Сохранить слово"

Сохранение должно продолжать работать через SQLite.

Команда /mywords должна показывать последние 10 сохранённых слов.

Обязательно обработать:

- /word без аргумента;
- неизвестное слово;
- пустой ответ API;
- timeout;
- сетевую ошибку;
- неожиданный формат JSON;
- повторное сохранение одного слова.

Существующий функционал EnglishMate не ломать:

- /start
- /lesson
- /progress
- /help
- placement test
- персональные уроки

Требования:

- Python 3.9
- python-telegram-bot 22.5
- SQLite
- python-dotenv
- httpx
- сохранить обработку Telegram timeout
- токен Telegram хранить только в .env
