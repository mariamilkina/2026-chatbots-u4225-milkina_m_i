# EnglishMate — Lab 3

EnglishMate — Telegram-бот для изучения английского языка.

В текущей версии бот умеет:

- определять примерный уровень английского A1–B2;
- создавать персональные уроки с учётом уровня и цели;
- переводить слова с русского на английский и с английского на русский;
- показывать значения и примеры употребления слов;
- сохранять слова в личный словарь;
- повторять сохранённые слова в формате мини-теста;
- показывать прогресс пользователя;
- работать через кнопочное меню без необходимости запоминать slash-команды;
- использовать Groq для генерации уроков, перевода и проверки свободных ответов;
- использовать fallback-механику при временной недоступности внешнего API.

## Технологии

- Python 3
- python-telegram-bot
- SQLite
- httpx
- Merriam-Webster API
- Groq API

## Переменные окружения

Для запуска необходимо создать `.env`:

~~~env
TELEGRAM_BOT_TOKEN=your_bot_token_here
MERRIAM_WEBSTER_API_KEY=your_merriam_webster_key_here
GROQ_API_KEY=your_groq_api_key_here
~~~

Настоящие API-ключи в репозиторий не добавляются.

## Локальный запуск

~~~bash
pip install -r requirements.txt
python3 bot.py
~~~

## Проверка

Для автоматической проверки используется:

~~~bash
python3 qa_check.py --live
~~~

QA проверяет структуру проекта, уроки уровней A1, A2, B1 и B2, работу перевода и проверку свободных ответов.

Последняя проверенная версия прошла автоматические тесты без критических ошибок.
